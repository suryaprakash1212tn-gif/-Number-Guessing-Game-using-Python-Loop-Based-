# -Number-Guessing-Game-using-Python-Loop-Based-
This Python program is a number guessing game. The program stores a fixed secret number and repeatedly asks the user to guess it. Using a while loop, the program continues running until the user enters the correct number. After each guess, the program checks whether the guessed number is less than, greater than, or equal to the secret number and gives appropriate feedback. When the correct number is guessed, a success message is displayed and the loop stops.

This program demonstrates the use of:

Variables

while loop

Conditional statements (if, elif, else)

User input and type conversion
